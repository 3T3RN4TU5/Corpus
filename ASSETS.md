# Assets

## 3D anatomy models

Models are in `public/models/`, one folder per body. Data with different licences stays in separate files, named `<source>-<layer>-<detail>.glb`.

| Files | Source | Licence | What it provides |
| --- | --- | --- | --- |
| `hra-*.glb` | [HuBMAP Human Reference Atlas, CCF 3D Reference Object Library](https://github.com/hubmapconsortium/ccf-3d-reference-object-library) v1.2, built from the Visible Human Project | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) | Female and male skin, eyes, brain regions, heart chambers, organs, trunk blood vessels, pelvis, vertebrae and spinal cord |
| `bp3d-*.glb` | [BodyParts3D](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/desc.html), © The Database Center for Life Science | See the licence question below | Skeleton, teeth, muscles, limb vessels, stomach, esophagus, tongue, some glands, and male genital structures, from one male body |
| `illustrative-*.glb` | Generated by `tools/blender/illustrative.py` and `build_bodies.py` | Part of this project | Hand-placed peripheral nerves, lymph nodes, the thoracic duct, the thyroid, rectus abdominis, latissimus dorsi, and the fat layer |

All of these were reduced in detail and compressed. BodyParts3D anatomy was also reshaped to fit each body.

### Licence question to resolve before wide distribution

The BodyParts3D [licence page](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/lic.html), updated in February 2025, says CC BY 4.0. The downloaded v4.0 files carry a header saying CC BY-SA 2.1 Japan. The project credits the source under either licence and keeps these models in their own `bp3d-*` files, so they can be distributed under share-alike terms if that is what applies. This is not legal advice. Ask the database or a lawyer if Corpus will be distributed commercially.

### Rebuilding the models

The raw data is about 430 MB and is not in the repository.

```bash
npm run models:fetch
```

```bash
blender --background --factory-startup --python tools/blender/build_bodies.py -- .assets-raw public/models build.log
```

Then copy `public/models/manifest.json` to `src/data/models.manifest.json`. The two archives in `.assets-raw/bp3d` must first be extracted into folders with the same names. The BodyParts3D server drops long downloads, so `models:fetch` resumes and may take a while.
